# Sprint 1.1 - Globalized Project Management

## 1. Project Description

This project consists of developing a web application to manage globalized educational projects for the second year of Web Application Development (DAW).

The application will provide a centralized platform where administrators, teachers and students can access and manage project-related information according to their roles.

## 2. Project Objectives

The main objectives of the application are:

- Centralize the management of educational projects.
- Manage users with different roles and permissions.
- Organize projects and their evaluable items.
- Assign teachers and students to projects.
- Allow teachers to grade students.
- Calculate average grades when multiple teachers evaluate the same item.
- Provide role-specific dashboards.
