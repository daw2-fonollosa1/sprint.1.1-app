
# Project Decisions

This document records the main decisions made during
the development of Sprint 1.1, including their
justifications and any unresolved questions.

## 1. Decisions Taken

### DEC-01: Initial Development Approach

**Decision:**
Start with project documentation, wireframes,
mockups and frontend development.

**Reason:**
Backend technologies have not yet been covered
in class. Backend development will begin later.

### DEC-02: Frontend Entry Point

**Decision:**
Use `frontend/index.html` as the initial
entry point of the application.

**Reason:**
Keep the main entry point separate from
the secondary application pages.

## 2. Pending Decisions

### PD-01: Authentication

- Which identifier will users use to log in?
- What information must be stored for each user?

### PD-02: User Permissions

- Which users can update and delete projects?
- Which users can update and delete evaluable items?
- Who will manage project assignments?
- Can teachers modify grades assigned by other teachers?

### PD-03: Grading System

- What grading scale will be used?
- How will average grades be rounded?

### PD-04: User Interface

- What navigation layout will be used?
- How will the dashboards be organized?
- What information will each dashboard display?

### PD-05: CSS Framework

The original project specification requires CSS
without frameworks.

However, the teaching staff has verbally
authorized the use of Bootstrap.

The final decision on whether to use Bootstrap
is still pending.
