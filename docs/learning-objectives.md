# Learning Objectives

This document describes the learning objectives associated with Sprint 1.1.

## 1. M0487 - Development Environments

- Organize and manage a software development project.
- Use Git for version control.
- Manage development tasks using GitHub Issues and Projects.
- Work with branches, commits and pull requests.
- Maintain clear and organized project documentation.
- Test and verify the implemented functionality.

## 2. M0612 - Client-side Web Development

- Develop client-side functionality using JavaScript.
- Handle user interactions.
- Validate form inputs.
- Organize client-side code.
- Understand how the frontend communicates with the backend.

## 3. M0613 - Server-side Web Development

- Understand client-server architecture.
- Learn the fundamentals of PHP.
- Develop server-side application logic.
- Apply object-oriented programming.
- Understand the MVC architectural pattern.
- Manage user authentication and sessions.
- Access and manage data using MariaDB.

These objectives will be addressed when the required backend technologies have been covered in class.

## 4. M0614 - Web Application Deployment

- Understand the process of deploying a web application.
- Use Docker or Docker Compose.
- Separate application services into containers.
- Configure automated checks using GitHub Actions.

## 5. M0615 - Web Interface Design

- Analyze user interface requirements.
- Create wireframes and mockups.
- Design an intuitive navigation system.
- Develop responsive interfaces for desktop and mobile devices.
- Apply usability and accessibility principles.
